# Проверка карточек туров — демо

Черновик автоматической проверки карточек туров по чек-листу качества.

Открыть: https://azatilfakovich1993-coder.github.io/yarko-check/

## Что внутри

- 26 правил, из них 23 работают обычным кодом, без языковой модели
- прогон на карточках, собранных с публичных страниц
- правила включаются, отключаются и настраиваются на самой странице
- можно завести свою карточку — форма повторяет структуру карточки на сайте
- подсветка незаполненных полей прямо в форме, с пояснением и цифрами
- проверка фотографий: данные съёмки и поиск одинаковых снимков

Всё считается в браузере. Ничего никуда не отправляется.

## Оговорки

Смысловые проверки, помеченные «модель», посчитаны заранее — модель внутри
статичной страницы не запустить.

Глазами сверена одна карточка, остальные собраны автоматически: часть их
«нарушений» — пробелы сбора, а не самих карточек.
